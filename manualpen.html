1. Como Iniciar (Boot)

Para usar o sistema sem instalar nada no seu HD, siga estes passos:

1
Insira o pen drive em uma porta USB (preferencialmente USB 3.0/azul).
2
Ligue o computador e pressione repetidamente a tecla de Boot do seu PC.
Dica: As teclas mais comuns são F12, F11, F10, F8 ou ESC. Consulte a marca da sua placa-mãe ou notebook.
3
Selecione o dispositivo USB na lista e pressione Enter.

2. Ativando a Persistência

A persistência permite salvar arquivos e configurações no pen drive.

Ao ver o menu inicial do MX Linux:

  1. Navegue até a opção "Options" ou use as teclas de função indicadas na tela.
  2. Verifique se a opção Persist All (ou Persistência Total) está selecionada.
  3. Prossiga com o boot. Na primeira vez, o sistema pode pedir para criar o arquivo de persistência; apenas confirme os valores padrão.

3. Acessando a Suite Proton

O seu sistema já vem com os aplicativos Proton pré-instalados para sua segurança:

  • Proton VPN: Localizado no menu Internet. Use para mascarar seu IP em redes públicas.
  • Proton Mail/Drive: Atalhos disponíveis na barra de favoritos do navegador ou no menu de aplicativos.

4. Idioma e Teclado

Este Respin já está configurado em Português (Brasil) e teclado ABNT2. Caso precise ajustar:

  • Vá em Configurações > Teclado > Layout para gerenciar as teclas.
  • O fuso horário está definido para o horário de Brasília.
Importante: Ao desligar o sistema, sempre use a opção "Encerrar" do menu. Nunca puxe o pen drive com o computador ligado para evitar corromper seus dados salvos.
